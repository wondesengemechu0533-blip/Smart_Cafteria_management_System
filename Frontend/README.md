#  Smart Cafeteria Ordering System

## 📌 Project Overview

The Smart Cafeteria Ordering System is a modern, responsive web-based application designed to digitalize and streamline cafeteria operations. It replaces traditional manual ordering processes with an efficient digital platform that enables customers to browse digital menus, place remote orders,  chapa  payments, and track order status in real-time.

The system provides dedicated dashboards for customers, kitchen staff, and administrators, making cafeteria management more efficient and organized. It is designed to be flexible and scalable, suitable for universities, hotels, restaurants, cafes, private cafeterias, company cafeterias, hospitals, and other food service organizations.

## 🚀 Features

### 👤 Customer
- Browse menu with categories
- Search and filter food items
- Add/remove items to/from cart
- Place orders remotely
- Simulate payment (Chapa)
- Track order status in real-time
- View order history
- Receive notifications

### 🍳 Kitchen Staff
- View incoming orders
- Update order status (preparing → ready → served)
- Mark orders as ready
- Manage preparation queue

### 👑 Administrator
- Manage users
- Manage menu items & categories
- View all orders
- Monitor payments
- Generate reports (daily, sales, popular items)
- Configure system settings
